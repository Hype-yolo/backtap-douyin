# 验证范围

验证日期：2026-09-19。状态：v0.2.0 公共试用版，安装页和解析服务已上线。

## 已验证

- 19 项本地单元测试通过：输入提取、域名与重定向限制、目标视频 ID 匹配、媒体地址校验、私有模式认证、错误脱敏、公共额度持久化、限流，以及解析卡住时的超时恢复回调。
- 公共版安装包包含 23 个动作，已签名；预填公共 HTTPS 地址，无密钥设置动作。线上下载文件与签名产物逐字节一致。
- macOS“快捷指令”实际运行公共版：复制目标短链接，读取剪贴板，通过公共 HTTPS 解析、下载并保存到“照片”；随后打开照片中的新视频，核对内容并实际播放，时间轴正常推进。目标为 MrBeast 的“苹果发布会刚结束，谁想要新手机！”（作品 ID 7685290972925709587）。
- Ubuntu 24.04、Node.js 20.20.2 上，以独立用户及 Chromium 沙箱取得公开目标视频的信息。没有导入个人登录 Cookie。
- 服务器之外完整下载返回的媒体文件；ffprobe 验证：1080×1920、H.264、AAC、33.733734 秒、9,401,019 字节。
- HTTPS 安装页实际渲染成功、下载入口可取到安装包、健康检查返回 v0.2.0。健康检查本身不代表解析成功。
- systemd 服务已设置开机启动；单解析并发 1、450 MiB 内存硬上限、一个 CPU 核算力上限、禁用本服务交换内存。测试峰值接近内存上限，仍需持续观察，不能视为规模化容量证明。
- 发现内存软限制可能使浏览器长时间停滞，已移除软限制、保留硬上限；请求超过 50 秒时返回超时并由 systemd 恢复本服务。
- 检查时已有三个常驻产品服务保持 active；新路由隔离在 /backtap/，未替换原有站点。

## 尚未验证 / 不承诺

- iPhone 的完整“安装 → 权限允许 → 轻点背面 → 剪贴板 → 下载 → 照片”实机验收。Mac 成功不能替代这项验证。
- 多人长期并发、持续成功率、所有作品、所有地区网络和所有 iOS 版本。
- 固定画质、去水印、平台接口长期兼容、用户不需要任何权限确认。
- 资源限制可控制本服务占用，不等于承诺共享服务器绝不会受到影响。

公共额度：所有人每天合计 100 次有效链接请求，按 UTC 日期更新；每个网络地址每分钟最多 5 次。解析失败也可能消耗已受理额度。安装包可供添加不等于每台 iPhone 均已验证；请先手动运行并核对真实相册文件，再绑定轻点背面。

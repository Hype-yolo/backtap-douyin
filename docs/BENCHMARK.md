# 对标：抖音无水印快速版

2026-09-19：用户确认这是当前 iPhone“轻点背面两下”绑定、可以使用的指令。本次通过 Mac 快捷指令编辑器只读查看其同步副本；没有执行、改写或重新绑定原指令。

## 实际流程

1. 接受分享表单输入；没有输入时读取剪贴板。
2. 请求 rcuts 的远程更新配置，读取版本、解析接口等字段。
3. 从输入提取网址；没有网址时请求用户粘贴。
4. 向解析 API 发送 POST 表单，字段为 url、token、clipboard。其中 clipboard 引用原始剪贴板变量 clip。
5. 判断响应 code，读取 video_url；由手机请求视频地址并保存到 Recents 相册。
6. 最后显示“下载完成，请前往相册查看”。此通知位于解析成功条件之外，存在未保存也可能提示完成的路径。

其配置入口为 http://i.rcuts.com/update/249，本次读取的 api 指向 http://api.rcuts.com/Video/DouYin_All.php。它依赖第三方在线解析服务；不能由快捷指令的本地动作推断对方后台实现、资源消耗、许可证、服务承诺或允许公开集成的额度。本次没有复制或使用 token，也没有向该 API 提交剪贴板或视频链接。

## 对我们的实现的影响

- 用户体验沿用“复制链接 → 轻点两下 → 相册”；背面触发不需要额外的剪贴板监控程序。
- 手机直接下载视频；我们的服务器只返回视频地址，避免承担视频转发流量。
- 只发送提取、验证后的抖音网址，不上传整个剪贴板。
- 成功通知只放在保存相册之后；解析失败需要明确提示。
- 第三方快捷指令和解析 API 不纳入我们的 MIT 代码，不把既有服务视为可免费推广的公共后端。
- 当前自建浏览器解析仍需证明能在共享服务器资源限额内可靠工作；原指令可用并不代表自建后端已可用。

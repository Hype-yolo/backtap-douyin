# iPhone 安装教程：直接使用版

**不需要服务器，不需要账号，不需要填写地址或密钥。** v0.2.0 的“轻点下载”已预填公共试用服务。

## 1. 添加快捷指令

在 iPhone 的 Safari 中打开 **[轻点下载安装页](https://hypeyolo.com/backtap/)**，点“添加『轻点下载』”。打开下载的 `.shortcut` 文件，选择“添加快捷指令”。

如果 Safari 把文件存进了“文件”App，从“下载项”点开它即可。名称若显示成下载文件名，可在快捷指令编辑页改名为“轻点下载”，或绑定背面手势时选择实际名称。

不要使用 v0.1.0 的自建安装包来体验公共服务；旧版需要自己填写服务器设置。

## 2. 第一次先手动运行

1. 在抖音打开一条公开视频，点“分享 → 复制链接”。
2. 回到“快捷指令”App，点“轻点下载”卡片运行。
3. 首次运行可能询问是否允许读取复制内容、访问 `hypeyolo.com`、访问抖音视频 CDN、存入照片。确认用途后允许。
4. 等待下载完成，打开“照片”，核对视频内容并试播。

解析通常需要等待几十秒。运行期间保持手机解锁，不要连续重复触发。首次系统权限需要你处理，不能自动跳过。

## 3. 绑定轻点背面

打开：

**设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下 → 轻点下载**

英文系统：Settings → Accessibility → Touch → Back Tap → Double Tap。

轻点背面需要兼容机型，参见 [Apple 官方说明](https://support.apple.com/zh-cn/111772)。找不到该设置时，仍可从快捷指令 App 手动运行。

## 以后每次使用

**抖音复制链接 → 轻点两下手机背面 → 等待 → 在相册查看视频。**

不需要再打开本项目网站或填写任何设置。

## 公共服务的试用限制

- 所有人合计每天最多受理 100 次有效链接请求，按 UTC 日期更新（北京时间上午 8 点）。已受理但解析失败的请求也计入额度。
- 每个网络地址每分钟最多 5 次；服务同时处理一个视频，繁忙时请稍后再试。同一 Wi-Fi 下的用户可能共享限额。
- 只支持公开的单条视频，暂不支持图集、直播或批量下载。
- 平台验证、网络、作品状态和平台接口变化会影响成功率；试用服务不提供持续可用保证。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 没有抖音链接 | 回到目标视频，重新点“分享 → 复制链接” |
| 系统询问联网、粘贴或照片权限 | 确认服务域名和用途后允许；系统首次会询问 |
| 正在处理其他下载 | 等一分钟再试，不要连续敲击 |
| 今日额度用完 | 北京时间次日上午 8 点后重试，或选择自行部署 |
| 抖音暂未返回视频信息 | 稍后尝试另一条公开视频；遇到平台验证时本服务不会自动处理验证码 |
| 有提示但没看到视频 | 在“照片”的最近保存/最近项目中核对；实际视频出现并能播放才算成功 |
| 手动运行成功，双击背面无反应 | 检查是否绑定到正确名称、机型是否支持和敲击方式 |
| 下载很慢或失败 | 保持手机解锁及网络连接；冷启动解析可能需要 20–45 秒，不要同时运行多个任务 |

想自己维护服务，请查看[部署教程](DEPLOY.md)和[自建版手机配置说明](SELFHOST-INSTALL.md)。普通用户不需要阅读这些步骤。

# 自建版 iPhone 配置教程

## 开始前先确认这一点

本页仅适用于自建版。普通用户请阅读[直接使用版安装教程](INSTALL.md)，无需执行下面的配置步骤。自建用户请先向服务管理员取得：

1. **服务地址**，例如 `https://download.example.com`。如果部署在子路径，填写完整基础地址，例如 `https://example.com/backtap`。末尾不要加 `/`，不要加 `/v1/resolve`。
2. **服务密钥**。将它视为访问凭据，不要公开分享。

没有这两项时，请先按[自建服务教程](DEPLOY.md)部署后端；仅安装快捷指令不能下载。

## 1. 添加快捷指令

在 iPhone 上用 Safari 打开项目的 [Releases 页面](https://github.com/Hype-yolo/backtap-douyin/releases/tag/v0.1.0)，下载 `backtap-douyin.shortcut`，打开文件，选择“添加快捷指令”。如果浏览器把文件保存到“文件”App，从“下载项”点开它即可。

如果添加后名称显示为 `backtap-douyin` 或下载文件名，可在编辑页面把它重命名为“轻点下载”；也可以保留名称，绑定背面时选择实际名称。

这是实验性版本。安装后先手动测试，再绑定背面手势。

## 2. 填写两项设置

打开“快捷指令”App，找到“轻点下载”，点卡片右上角的 **…**，进入编辑页面。

- 顶部第一个“文本”动作：将 `https://your-server.example` 替换成管理员提供的服务地址。
- 顶部第二个“文本”动作：将“填写你的服务密钥”替换成管理员提供的密钥。

不要修改后面的动作。点“完成”。不要把填有密钥的指令重新发布或分享给不应使用该服务的人。

## 3. 先手动下载一次

1. 在抖音打开一条公开视频，点“分享 → 复制链接”。
2. 回到“快捷指令”，点“轻点下载”卡片运行。
3. 系统可能第一次询问是否允许粘贴、访问服务域名、访问视频 CDN、存入照片。确认域名和用途后允许。
4. 等待完成，打开“照片”，确认出现了刚才的视频，并能播放。

冷启动解析可能需要几十秒。系统权限提示需要手动处理，首次运行并不是完全无交互。必须看到相册里的真实视频，才算这一步完成。

## 4. 绑定轻点背面

在 iPhone 打开：

**设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下 → 轻点下载**

英文系统对应：Settings → Accessibility → Touch → Back Tap → Double Tap。

轻点背面需要兼容的 iPhone；参见 [Apple 官方说明](https://support.apple.com/zh-cn/111772)。如果没有这一选项，可以从快捷指令 App 手动运行。

此后每次使用：**复制抖音链接 → 轻点两下背面 → 等待 → 在相册查看视频**。运行期间保持手机解锁，避免重复连续触发多个下载。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示没有抖音链接 | 回到目标视频，重新点“分享 → 复制链接” |
| 提示密钥不正确 | 检查第二个文本动作，注意前后空格 |
| 无法连接服务 | 确认第一个文本动作是实际部署的 HTTPS 地址，管理员服务已启动 |
| 平台未返回视频 | 可能遇到网络、平台限制或作品不可用；稍后尝试另一条公开视频 |
| 提示繁忙或请求较多 | 等一分钟再试；不要连续敲击 |
| 公共服务额度耗尽 | 次日再试或询问该服务的管理员；自建模式的额度由管理员决定 |
| 有完成通知但找不到视频 | 检查“照片 → 最近保存”等视图；不要把只有通知当作保存成功 |
| 手动运行成功但背面无反应 | 检查绑定的名称、机型支持和敲击方式，参考 Apple 说明 |
